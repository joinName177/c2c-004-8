# 替代组合试算设计说明

2026-10-06 追加，基于《行李箱空间规划师设计说明》。

## 目标

用户常在可互相替代的物品之间犹豫（厚外套/薄外套、相机/手机配件），此前只能反复删加物品试效果。本功能允许把互替物品编入一组，由系统在“每组最多选一件”的约束下按当前策略组合试装，并给出可解释的推荐。

## 规则

### 分组

- 每组至少两件物品，一件物品只能属于一个组；组内物品顺序即偏好（越靠前越优先）。
- 整组可标记为必带或可选。必带组必须有一件实际装入；可选组允许一件都不带。
- 组内任一物品被标为必带时，该组不得变为可选：创建/修改分组时校验拦截；物品在可选组内被标必带时，所在组自动升级为必带组并提示。
- 删除物品后，不足两件的分组自动解散。

### 试算

- 枚举每组的选择（必带组：每个成员；可选组：每个成员 + 不携带），与未分组物品合成试装清单，用当前选中策略运行装箱引擎。
- 所有组合都基于当前清单的独立副本，试算不改动原清单。
- 候选排序依次比较：必带满足情况（必带组满足数、必带物品装入数）→ 组内偏好得分 → 重量余量；完全并列时按选择签名确定性取舍。
- 计算预算为 400 种组合。超出预算时返回已找到的最优可行方案，界面明确标注“不代表全局最优”。
- 找不到完整解时，明确列出未满足的必带组。
- 每个非推荐候选都给出被放弃的原因（第一条分出胜负的比较项）。

### 确认与失效

- 确认后保存分组与本次选择，并据此重新生成三套方案；此后装箱、风险与打印清单均使用“未分组物品 + 每组选中一件”的有效清单。
- 试算结果记录清单、分组与行李箱的指纹；原清单变化后旧推荐立即失效，需重新试算才能确认。

## 实现

- `src/core/alternative-engine.ts`：分组校验、有效清单、指纹、组合枚举与候选评估（纯函数，不依赖浏览器）。
- `src/core/snapshot.ts`：旧版本地数据缺少分组字段时补默认值。
- `src/ui/components/AlternativePanel.vue`：分组编辑、偏好排序、试算结果与确认。
- 快照新增 `alternativeGroups` 与 `alternativeSelection`，随 localStorage 持久化。
